Professional Self-Assessment

Completing the Computer Science program and developing this ePortfolio has allowed me to reflect on both my technical growth and my professional development. Throughout the program, I strengthened my abilities in software development, database design, algorithms, security, and problem solving while learning how these areas work together to create effective computing solutions. As I progressed through my coursework, I also refined my career goals. I initially entered the program through the Game Programming and Development path and later became interested in front-end web development. While those areas provided valuable experience, I ultimately discovered a strong interest in data analytics and data science. This shift helped shape my professional goals and motivated me to further develop my programming, database, and analytical skills.

One of the most valuable lessons I learned throughout the program was the importance of collaboration and communication. Courses such as CS 250 emphasized working with stakeholders, gathering requirements, and communicating technical information to different audiences. I learned that successful software projects depend not only on technical implementation but also on understanding user needs and maintaining clear communication throughout the development process. Creating project documentation, design plans, presentations, and code reviews helped me develop professional communication skills that are essential when working with development teams, managers, clients, and stakeholders.

The program also strengthened my understanding of data structures and algorithms. Through coursework and enhancement projects, I learned how selecting appropriate data structures and designing efficient algorithms can improve software performance and maintainability. I gained experience working with collections, sorting techniques, searching methods, and algorithmic problem solving. These skills were further reinforced through the enhancement of my inventory management application, where I implemented inventory sorting functionality and additional business logic to improve data organization and usability.

Software engineering principles became increasingly important as I progressed through the program. I learned how to design maintainable systems using object-oriented principles, layered architectures, and software development best practices. My coursework exposed me to the software development lifecycle, requirements analysis, testing methodologies, and application design patterns. Through my capstone enhancements, I refactored existing code into repository and service layers, improving separation of concerns and reducing coupling between application components. These experiences strengthened my ability to evaluate existing systems and implement improvements that increase scalability and maintainability.

Database design and management also became a significant area of growth. Throughout the program, I worked with SQL databases, database normalization concepts, CRUD operations, and data modeling. My coursework demonstrated the importance of organizing data efficiently while maintaining data integrity and supporting future scalability. Through my database enhancement, I expanded the inventory application to support user-specific inventory records by introducing relationships between users and inventory items. This enhancement improved data organization and more closely reflected real-world database design practices.

Security has remained an important consideration across multiple courses and projects. I learned how software vulnerabilities can affect both organizations and end users and developed a greater appreciation for secure design principles. Coursework in secure coding, software development, and mobile application development emphasized authentication, authorization, data protection, and risk mitigation. Within my portfolio artifact, security considerations include user authentication, controlled access to inventory records, and proper handling of application permissions for SMS notifications. These experiences helped me develop a security mindset that considers potential vulnerabilities during the design and implementation process rather than treating security as an afterthought.

The artifacts included in this ePortfolio collectively demonstrate my growth throughout the Computer Science program. The code review serves as the foundation of the portfolio by evaluating the original application and identifying opportunities for improvement. The software engineering enhancement demonstrates my ability to improve application architecture through the implementation of repository and service layers. The algorithms and data structures enhancement highlights my ability to apply sorting and search functionality to improve application usability and efficiency. The database enhancement showcases my understanding of relational database concepts through the implementation of user-specific inventory management and improved data organization. Together, these artifacts demonstrate a combination of software engineering, database management, algorithmic problem solving, communication, and security skills developed throughout the program.

As I prepare to complete the Computer Science program, I feel confident in the technical foundation I’ve developed and excited about continuing my professional growth. The knowledge and experience gained through coursework, projects, and portfolio development have prepared me to contribute effectively in technical environments while continuing to pursue my long-term interest in data analytics and data science. This ePortfolio represents both the skills I’ve developed and the progress I’ve made toward becoming a well-rounded computing professional.
