Software Design and Engineering Enhancement

This enhancement focused on improving the software architecture of the InventStory Android inventory application. To improve maintainability and scalability, I implemented repository and service layers, reorganized project packages, and introduced a layered architecture that separates user interface, business logic, and data access responsibilities.
