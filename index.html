Software Design and Engineering Enhancement

This enhancement focused on improving the software architecture of the InventStory Android inventory application. The original application relied heavily on Activity classes for application logic and database interactions. To improve maintainability and scalability, I implemented repository and service layers, reorganized project packages, and introduced a layered architecture that separates user interface, business logic, and data access responsibilities.

Algorithms and Data Structures Enhancement

This enhancement focused on improving the algorithmic functionality of the InventStory application. I implemented inventory sorting and filtering features through a dedicated service layer, allowing inventory items to be organized by quantity and identified based on low-stock thresholds. These changes demonstrate the use of algorithms, collections, and data processing techniques to improve the user experience while maintaining clean application architecture.

Database Enhancement

This enhancement focused on improving the database design of the InventStory application by establishing relationships between users and inventory records. I redesigned the inventory database structure to associate items with specific users and implemented user-specific queries to retrieve only the inventory belonging to the authenticated user. These improvements increased data organization, scalability, and data integrity.
